## Запрос

```bash
voiceover search "сценарный текст" --mode lexical --json
voiceover search "сценарный текст" --mode lexical --scope directions --limit 10
```

`--mode lexical` — офлайн FTS5 по сохранённой истории: сценарии, распознанные транскрипты и пользовательские метки. Ключ, FFmpeg, Torch, `sqlite-vec` и сеть не нужны. Запрос трактуется как литеральные слова; пустой запрос отклоняется (`SEARCH_EMPTY_QUERY`, exit `2`).

## Режим по умолчанию

`--mode` можно не указывать: тогда режим берётся из несекретного `<CWD>/settings.toml`, секция `[search] default_mode` (default `lexical`). Явный `--mode` побеждает всегда — даже если `settings.toml` испорчен. Если `--mode` не задан и консультируемый файл невалиден или `default_mode` не `lexical|semantic|hybrid`, команда fail-closed **до** открытия базы: exit `2`, `SEARCH_SETTINGS_INVALID`, сообщение без пути и содержимого файла. Настроенный `semantic`/`hybrid` доходит до честного `SEARCH_MODE_DEFERRED` (exit `2`) без входа в базу и без моделей. Режим читается только из `settings.toml`, никогда из `.env`.

## Фильтры

| Флаг | Смысл |
|---|---|
| `--scope speech\|directions\|all` | роль текста: речь и ASR по умолчанию, `directions` добавляет режиссёрские инструкции |
| `--limit` | размер выдачи, от `1` до `500`, по умолчанию `20` |
| `--kind`, `--role` | точный фильтр вида источника или роли |
| `--run`, `--operation` | точный UUID прогона или операция |
| `--provider` | прогон, у которого есть попытка с этим провайдером |
| `--since`, `--until` | границы по дате создания прогона |

Все фильтры применяются в SQL до `LIMIT`. Приватный ASR-контекст не индексируется: это входная подсказка, а не распознанная речь.

## Индекс

```bash
voiceover index status --json
voiceover index build --json
voiceover index rebuild --json
```

Индекс производный: он собирается только из SQLite и никогда не пересканирует пользовательские файлы. `status` открывает базу только для чтения. Если история отсутствует, `search` вернёт пустой результат с предупреждением и ничего не создаст; если лексический слой не построен — предупреждение и подсказку выполнить `voiceover index build`.

## Границы

- Найденный фрагмент — это фрагмент текста, а не новая часть синтеза: поиск не регенерирует и не оплачивает аудио.
- Временные диапазоны фрагмента могут быть `null`: время показывается только при наблюдённых span, а не по догадке.
- Отсутствие совпадений не доказывает отсутствие темы в аудио: полнота транскриптов и индекса ограничивает вывод.
- Semantic и hybrid сюда не входят: `voiceover help search.semantic`.
