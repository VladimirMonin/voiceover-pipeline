# Qwen3-TTS локально

Qwen/Qwen3-TTS — open-source модель синтеза речи. Работает локально на GPU (NVIDIA, CUDA), полностью бесплатно.

Для разработки из репозитория: `uv sync --extra voiceover-qwen`.

## Модели

| Модель | HuggingFace ID | Размер | Назначение |
|---|---|---|---|
| CustomVoice | `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice` | 1.7B | Девять официальных preset-голосов |
| Base | `Qwen/Qwen3-TTS-12Hz-1.7B-Base` | 1.7B | Клонирование голоса из референс-аудио |

Обе модели работают с десятью основными языками, включая русский. CustomVoice поддерживает управление стилем через `instruct`.

| `Eric` | М | Живой слегка хриплый тембр / китайский, сычуаньский диалект |

| `Aiden` | М | Солнечный американский голос с ясной серединой / английский (**дефолт**) |

Каждый preset может говорить на русском. Для лучшего результата задавайте
конкретный стиль на один прогон через `--qwen-instruct`:

```bash
voiceover generate --provider qwen-local --mode preset --voice Serena \
  --qwen-instruct "Спокойная, уверенная, мягкая подача новостного ведущего."
```

Если флаг не указан, используется `QWEN_INSTRUCT` из `config.py`.

## Клонирование голоса (clone)

Для режима clone нужен референс-аудиофайл. Подойдёт 10-30 секунд чистой речи одного диктора.

```powershell
voiceover generate --provider qwen-local --mode clone --sample "my_voice_sample.mp3"
```

Если референсного текста нет (`--sample-text` пуст) — используется `x_vector_only_mode=True`, модель клонирует тембр без привязки к тексту референса.

```powershell
# С точным текстом референса (точнее клонирование):
voiceover generate --provider qwen-local --mode clone `
  --sample "my_voice_sample.mp3" `
  --sample-text "Текст, который произносится в референсе."
```

## Нативная история и resume (clone, preset, design)

Обычные не-диалоговые режимы `clone`, `preset` и `design` идут через
каноническую SQLite-историю (нативный маршрут). Для `clone` снимок хранит
локатор референс-файла, его SHA-256 и размер, точный reference text, а также
модель, режим и выбранный рантайм/язык; сами байты референса не копируются ни в
снимок, ни в публичные JSON. Для `preset`/`design` снимок хранит свой блок
идентичности: режим, модель (CustomVoice/VoiceDesign), голос пресета (или
маркер `design`), точную инструкцию, рантайм и язык. Инструкция для
`preset`/`design` — это `--qwen-instruct` (или `QWEN_INSTRUCT`) и остаётся
публичным полем `style_prompt`, как и на legacy-маршруте; рантайм/язык в
публичные JSON не попадают.

- Перед первой локальной частью проверяются установленный локальный рантайм с
  кэшированной моделью (без скачивания); для `clone` дополнительно референс-файл.
  Пропавший/изменённый референс или смена рантайма завершают прогон до вызова
  модели (`NATIVE_LOCAL_REFERENCE_UNAVAILABLE`, exit `30`), недоступная
  зависимость или некэшированная модель — `NATIVE_LOCAL_MODEL_UNAVAILABLE`,
  exit `10`. Смена `--qwen-instruct` (или голоса/модели) блокирует resume как
  `NATIVE_RESUME_IDENTITY_CHANGED`.
- `generate --resume` и `history resume ID` продолжают прогон без исходного
  сценария: завершённые части не перегенерируются, часть с сохранёнными raw-байтами
  пересобирается локально без повторного запуска модели, а изменённый/пропавший
  референс или изменённая идентичность блокируют resume до модели.
- `history sync ID` не запускает модель: незавершённая часть сообщает
  `NATIVE_SYNC_LOCAL_SYNTHESIS_REQUIRED`, завершённый прогон только переписывает
  совместимые JSON-экспорты из БД.
- `--mode auto` не реализован: он отклоняется как usage error (`exit 2`) до
  провайдера, модели и снимка, без подмены режима на `preset`. `--no-trim`,
  `--with-timings` и `--tts-quality-provider` пока остаются на legacy-маршруте без
  SQLite-истории.

## Как работает

1. Загружается модель Qwen3-TTS (1.7B параметров) на GPU
2. Для каждого чанка вызывается `generate_custom_voice` или `generate_voice_clone`
3. Результат — WAV через `soundfile`
4. WAV конвертируется в MP3 через FFmpeg
5. Временные WAV-файлы сохраняются в `temp/`

## Требования к GPU

- NVIDIA GPU с CUDA support
- ~4 GB VRAM для CustomVoice (1.7B параметров в bfloat16)
- ~4 GB VRAM для Base (clone)
- Модель скачивается из HuggingFace один раз и кешируется

Без GPU модель упадёт на CPU — слишком медленно для практического использования.

## Цена

Локальный Qwen не имеет внешнего API-начисления. На нативных локальных маршрутах
(`clone`/`preset`/`design`) стоимость остаётся `null` (неизвестной), а не
выдуманным нулём, и каждая реальная локальная попытка учитывается в
`history costs` как `local_attempts_without_api_charge`. Legacy-маршруты (смеси с
`--no-trim`/`--with-timings`/`--tts-quality-provider`) помечают
стоимость как `qwen-local (free)`.
