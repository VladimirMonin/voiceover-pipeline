## Offline gates на версии 0.7.0

- Fail-first версия: после изменения только `pyproject.toml` `test_package_version_matches_pyproject_metadata` упал (`0.6.1` против `0.7.0`); после согласования источника и тестов focused **86 passed** (`test_execution_identity.py`, `test_generation_stability.py`). Финальный полный `uv run --offline --frozen pytest -q -p no:cacheprovider tests` — **2407 passed, 2 skipped**; Ruff check/format — PASS (194 форматированных файла), mypy `--no-incremental` — PASS (92 source files), `git diff --check` — PASS. Skips не объявляются успехом native Windows или частного WVM corpus.
- На macOS arm64, Python 3.13.2, SQLite 3.45.3 реально создана in-memory FTS5-таблица и выполнен MATCH; FFmpeg 8.1 установлен. Прежний S11 fake TTS/ASR → real FFmpeg/SQLite/FTS5 → safe recovery/Decimal — **ACCEPT_OFFLINE**, а не live cloud или локальная модель.
- Реальный приватный YAML 12 частей проверен **без сети** через source CLI и отдельно из установленного wheel вне checkout: `validate` возвращает `valid: true`, `parts: 12`, без флага `route.admitted: false` / `BLOCKED_PROVIDER_CONTRACT`, с флагом `route.admitted: true`; `validate` не делает POST.
- `uv lock --offline` не смог пересчитать lock из-за отсутствующего `openai>=2.32.0` в offline cache (resolver проверял иные supported marker splits); **без сети** изменена только root-версия пакета в прежнем lock. `uv lock --locked --offline` **PASS** (144 зафиксированных пакета; lock diff — ровно одна строка root version), затем `uv run --offline --frozen` собрал/установил editable 0.7.0 и выполнил тесты. Это **не** доказательство нового полного dependency resolution или чистой установки во всех средах.

## Release boundary

Владелец разрешил **для этого релиза** изменение версии, локальную сборку, Git tag, push ветки/тега и GitHub Release после проверки точного commit/архивов. PyPI и любые другие package registries **не разрешены**. Успех GitHub Release следует удостоверить отдельной удалённой проверкой; местные тесты, tag или push поодиночке не являются доказательством опубликованного Release.
