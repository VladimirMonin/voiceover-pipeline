# Провайдеры распознавания речи и таймингов

> АГЕНТ: ЧИТАЙ ЭТОТ ФАЙЛ ЦЕЛИКОМ.
> Здесь: локальное и облачное распознавание, модели, таймкоды и ограничения.

## Обзор

| Провайдер | Где работает | Ключ | Что возвращает |
|---|---|---|---|
| `faster-whisper` | Локально | Не нужен | Текст, сегменты, таймкоды слов |
| `openrouter-whisper` | Облако OpenRouter | `OPENROUTER_API_KEY` | Только полный текст, без таймкодов |
| `groq-whisper` | Облако Groq | `GROQ_API_KEY` | Сегменты и таймкоды слов |
| `xai-stt` | Облако xAI | `X_AI_API_KEY` | Таймкоды слов и уверенность распознавания |

## Faster-Whisper — локально

Работает на компьютере пользователя через `faster-whisper`. Аудио не отправляется
в облако. Модели скачиваются с Hugging Face при первом реальном запуске.

| Модель | Размер | Практический смысл |
|---|---:|---|
| `base` | ~148 MB | Быстро, точность ниже |
| `small` | ~486 MB | Значение по умолчанию, разумный выбор для русского |
| `medium` | ~1.5 GB | Точнее, но тяжелее |
| `large-v3-turbo` | ~1.6 GB | Хорошая точность, требует больше ресурсов |
| `large-v3` | ~3.0 GB | Максимальная точность, самый тяжёлый вариант |

Возможности:

- посегментные таймкоды;
- таймкоды отдельных слов с `--word-timestamps`;
- CPU и CUDA;
- работа без API-ключа и оплаты.

Ограничения:

- модель нужно скачать;
- крупные модели требуют много памяти;
- на CPU длинное аудио обрабатывается заметно медленнее;
- CUDA зависит от совместимой NVIDIA-среды.

```bash
voiceover timings \
  --audio podcast.mp3 \
  --timing-provider faster-whisper \
  --model small \
  --language ru \
  --word-timestamps \
  --json
```

## OpenRouter Whisper — облако, только текст

Поддерживаемые модели:

- `openai/whisper-large-v3-turbo`;
- `openai/whisper-large-v3`;
- `openai/whisper-1`.

OpenRouter в текущем контракте проекта возвращает полный текст без настоящих
посегментных таймкодов. Поэтому CLI намеренно блокирует его для команды
`timings` и для `generate --with-timings` с кодом выхода 40.

Использовать его можно для облачной транскрипции текста, но не для SRT,
синхронизации сцен или подсветки слов.

## Groq Whisper — облако с таймкодами

Поддерживаемые модели:

- `whisper-large-v3-turbo` — значение по умолчанию, быстрее;
- `whisper-large-v3` — точнее, но медленнее и дороже.

Возможности:

- посегментные таймкоды;
- таймкоды отдельных слов;
- быстрое распознавание длинных записей;
- распространённые форматы: MP3, WAV, OGG, Opus, FLAC, M4A, WebM.

Ограничения:

- аудио отправляется внешнему сервису;
- нужен `GROQ_API_KEY`;
- стоимость, лимиты и доступность определяет Groq;
- живой вызов выполняется только после явного разрешения пользователя.

```bash
voiceover timings \
  --audio podcast.opus \
  --timing-provider groq-whisper \
  --model whisper-large-v3-turbo \
  --language ru \
  --json
```

## xAI STT — облако с таймкодами слов

Модель: `grok-stt`.

Возможности:

- таймкоды отдельных слов;
- показатель уверенности для каждого слова;
- автоматическая группировка слов в сегменты по паузам;
- поддержка нескольких аудиоформатов;
- API заявляет многоканальное распознавание и разделение говорящих.

Ограничения:

- аудио отправляется xAI;
- нужен `X_AI_API_KEY`;
- разделение говорящих и многоканальность поддерживаются API, но не все эти
  возможности обязательно выведены отдельными флагами текущего CLI;
- живой вызов и текущие цены требуют отдельной проверки и разрешения.

```bash
voiceover timings \
  --audio podcast.opus \
  --timing-provider xai-stt \
  --model grok-stt \
  --language ru \
  --json
```

## Как выбирать

| Задача | Рекомендация |
|---|---|
| Приватно и бесплатно | `faster-whisper` + `small` |
| Максимальная локальная точность | `faster-whisper` + `large-v3` |
| Быстро в облаке с сегментами и словами | `groq-whisper` |
| Нужна уверенность по словам | `xai-stt` |
| Нужен только сплошной текст | `openrouter-whisper` |
| Нужны SRT или тайминги сцен | Не использовать `openrouter-whisper` |

## Безопасность

- Никогда не читать и не печатать `.env`.
- Наличие ключей проверять через `voiceover doctor --json`.
- Не отправлять частное аудио облачному провайдеру без разрешения пользователя.
- Не обещать текущие цены и доступность по исторической документации.
- Для Remotion и субтитров использовать только провайдер, который реально
  возвращает временные метки.
